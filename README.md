# Nova Lite Solution – Official Website

![Nova Lite Solution](assets/images/logo.png)

Professional business website for **Nova Lite Solution**, a premium LED lighting brand based in **Kishanganj, Bihar, India**.

## 🌐 Live Preview
Deploy via [Netlify](https://netlify.com) or [GitHub Pages](https://pages.github.com) for instant hosting.

## 📄 Pages Included
| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Hero, Stats, Products, Testimonials |
| About Us | `about.html` | Company story, vision, mission |
| Products | `products.html` | Full product catalog with specs + filter |
| Gallery | `gallery.html` | Photo gallery with lightbox |
| Dealer Registration | `dealer.html` | Dealer/Distributor form |
| Contact Us | `contact.html` | Contact form + Google Map |

## 🖼️ Adding Product Images
Replace the placeholder images in `assets/images/` with your actual product photos:
- `led-bulb.jpg` – LED Bulb product photo
- `led-bulb-12w.jpg` – LED Bulb 12W photo
- `rechargeable-bulb.jpg` – Rechargeable Bulb photo
- `tube-light.jpg` – Tube Light photo
- `about.jpg` – Team/office photo
- `logo.png` – Company logo

## 🚀 Deployment (Free Hosting)
### Option 1: GitHub Pages
1. Go to Settings → Pages
2. Source: Deploy from branch → `main`
3. Save. Your site goes live at `https://Aditya3045v.github.io/nova-lite-solution`

### Option 2: Netlify (Recommended)
1. Go to [netlify.com](https://netlify.com)
2. Drag & drop this folder or connect GitHub repo
3. Done! Free SSL + custom domain support.
